# Reforma em Foco — Landing Page

Página de apresentação em português sobre preparação empresarial para a Reforma Tributária.

## Arquivos
- `index.html`: estrutura e conteúdo da página.
- `styles.css`: layout responsivo e identidade visual.
- `script.js`: ano do rodapé e resposta demonstrativa do formulário.
- `assets/brand-mark.svg`: marca gráfica provisória.

## Como visualizar
Abra `index.html` no navegador ou publique o repositório com GitHub Pages.

## Antes de publicar
- Substitua a marca provisória pela identidade visual oficial.
- Conecte o formulário a um serviço seguro de recebimento de leads; atualmente ele não transmite nem armazena dados.
- Revise textos e cronogramas tributários com profissional qualificado para manter as informações atualizadas.
- Inclua política de privacidade e consentimento adequados se passar a coletar dados pessoais.

O conteúdo é informativo e não constitui aconselhamento tributário ou jurídico.
