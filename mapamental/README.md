# Ideia — Mapa Mental

Aplicativo simples de mapas mentais em português, inspirado em ferramentas como MindMeister. Não exige login, cadastro ou instalação.

## Como usar
Abra `index.html` no navegador. O aplicativo usa HTML, CSS e JavaScript puro.

## Recursos
- Criar ideias-filhas e ideias-irmãs.
- Renomear e excluir nós.
- Navegar pelo mapa arrastando o fundo e ajustar o zoom.
- Salvamento automático no armazenamento local do navegador.
- Exportar e importar mapas em JSON.
- Interface responsiva para desktop e celular.

## Atalhos
- **Tab:** nova ideia filha.
- **Enter:** nova ideia irmã.
- **Duplo clique ou F2:** renomear ideia.
- **Delete / Backspace:** excluir ideia selecionada.
- **Esc:** selecionar a ideia central.

## Armazenamento e privacidade
Os mapas ficam salvos apenas no navegador em uso. Não há conta, sincronização ou envio dos dados a um servidor. Para guardar uma cópia ou mover o mapa para outro dispositivo, use **Exportar** e depois **Abrir mapa**.

## Arquivos
- `index.html`: interface do aplicativo.
- `styles.css`: estilos e layout responsivo.
- `app.js`: edição do mapa, salvamento e importação/exportação.

## Publicação
A pasta está em `mapamental/` dentro do repositório `lrtparticipacoes-creator/helho`. Para publicar este app de forma independente, a opção mais limpa é criar um repositório dedicado e ativar GitHub Pages para a raiz dele. A landing page existente na raiz do repositório foi preservada.
