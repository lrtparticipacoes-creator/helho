# Ideia — Mapa Mental

Aplicativo de mapas mentais em português, inspirado em ferramentas como MindMeister. Não exige login, cadastro ou instalação.

## Recursos
- Criar vários mapas e acessá-los pela biblioteca **Meus mapas**.
- Editar o título e escrever conteúdo diretamente dentro de cada quadro.
- Arrastar uma ideia sobre outra para movê-la e conectá-la como ideia filha.
- Criar ideias-filhas e ideias-irmãs, renomear e excluir quadros.
- Navegar pelo mapa arrastando o fundo e ajustar o zoom.
- Salvamento automático local.
- Exportar o mapa atual em JSON e importar mapas exportados.
- Interface responsiva para desktop e celular.

## Atalhos
- **Tab:** nova ideia filha.
- **Enter:** nova ideia irmã.
- **F2:** focar o título da ideia selecionada.
- **Delete / Backspace:** excluir ideia selecionada.
- **Esc:** selecionar a ideia central.

## Armazenamento e privacidade
Os mapas ficam salvos apenas no navegador em uso. Não há conta, sincronização ou envio dos dados a um servidor. Para guardar uma cópia ou mover um mapa para outro dispositivo, use **Exportar** e depois **Abrir mapa**. Limpar os dados do navegador pode apagar os mapas locais; mantenha cópias exportadas dos mapas importantes.

## Arquivos
- `index.html`: interface do aplicativo.
- `styles.css`: estilos e layout responsivo.
- `app.js`: edição, biblioteca, salvamento e importação/exportação.
